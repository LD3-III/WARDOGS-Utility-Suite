## 🔥 What is WARDOGS Utility Suite?

WARDOGS Utility Suite is a Windows-focused cheat and utility project for **WARDOGS**, built around a simple menu instead of a pile of separate tools.

The idea is straightforward: open the menu, pick the modules you want, tune the settings, save the profile and get back into the game. Everything is kept in one place so changing a setup takes seconds instead of digging through files every time.

> 🐺 **Clean menu. Fast setup. Configurable modules.**

Keep your aiming settings together in one place. Adjust the options available in your current build without constantly editing configuration files by hand.

Extra gameplay and interface options live here. The goal is a small set of useful controls rather than a menu filled with unnecessary switches.

### 💾 Configs

Create separate profiles for different setups and switch between them without rebuilding your configuration from scratch.

## 🚀 Usage

The usual workflow is simple:

**1. Start the suite**

Launch the current build on Windows.

**2. Open the menu**

Use the configured menu key to open the interface.

**3. Pick a module**

Choose the section you want and adjust the available settings.

**4. Save your profile**

Keep your preferred setup in a config profile so it can be loaded again later.
